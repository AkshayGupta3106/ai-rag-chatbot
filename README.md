# 🚀 Project Overview

This project is an **AI-powered document chatbot** that allows users to:

📄 Upload PDFs\
🤖 Ask questions about the document\
🧠 Get answers generated by a **local LLM**\
📚 See sources used for the answer

Runs locally and is perfect for experimenting with **AI engineering +
RAG systems**.

# ⚡ Quick Start

## Install dependencies

pip install -r requirements.txt

## Start backend

uvicorn main:app --reload

Backend runs at: http://127.0.0.1:8000

## Start frontend

streamlit run chat_ui.py

Frontend runs at: http://localhost:8501
